## 安装

1. 下载本页下方的 `RagfairMultiCurrency.dll`
2. 复制到 `<游戏目录>\BepInEx\plugins\RagfairMultiCurrency\`
3. 重启游戏

## 环境要求

| 项目 | 版本 |
|---|---|
| 游戏 | SPT 4.1.6 |
| 加载器 | BepInEx 5.4.23.5 |
| 运行时 | Harmony 2.9.0 / .NET Framework 4.7.2 |

纯客户端 UI 模组，不碰交易事务，Fika 联机无同步影响。
